# Session 3 data

Small subsets of real data for `Session_3_1_Python_Tools_for_Atmospheric_Science.ipynb`. Nothing here is simulated. The notebook runs offline from these files; files marked "optional live fetch" can be re-created from their source.

| File | What it is | Source | Window and subsetting |
|------|-----------|--------|-----------------------|
| `geos_cf_midatlantic_aug2025.nc` | NASA GEOS-CF surface air quality (variables PM2.5 at 35 percent RH, NO2, O3), hourly, 0.25 degree grid | NASA GMAO GEOS-CF, `aqc` collection, assimilation mode, via OPeNDAP: `https://opendap.nccs.nasa.gov/dods/gmao/geos-cf/assim/aqc_tavg_1hr_g1440x721_v1` | 2025-08-05 00:30 UTC to 2025-08-08 05:30 UTC (78 hourly averages); lat 34 to 43, lon -85 to -72; surface level only (the length-1 `lev` dimension dropped); NO2 and O3 converted from mol/mol to ppb (x 1e9). The source gives no units attribute for PM2.5; ug m-3 is taken from the atmoz documentation of this collection. |
| `states_midatlantic.geojson` | State outlines: the 8 states in the monitor table plus NY, OH, KY, TN, CT, SC for context | Natural Earth 1:10m admin-1 states and provinces (public domain), read through cartopy | Simplified with tolerance 0.001 degrees; columns `state`, `abbr`, `has_monitors`. |
| `pm25_daily_monitors_2025.parquet` | Daily PM2.5 per EPA monitoring site, 2025, 151 sites | Built from `data/epa_daily_pm25_2025_midatlantic.parquet` (EPA AQS daily summary, parameter 88101) | One row per site and date: mean of "Arithmetic Mean" over all POC and sample-duration rows for that site and date. Site id is state-county-site. The state name "District Of Columbia" was respelled "District of Columbia" to match the outlines. |
| `sounding_KIAD_2025-08-06_12Z.csv` | NWS radiosonde, Sterling VA (KIAD), 12 UTC, 182 levels | Iowa Environmental Mesonet RAOB archive: `https://mesonet.agron.iastate.edu/json/raob.py?ts=202508061200&station=KIAD` | Whole profile, unchanged, saved as CSV (pres hPa, hght m, tmpc, dwpc degC, drct degrees, sknt knots). |
| `sgpmetE13.b1.20190101.000000.cdf` | ARM surface meteorology (MET), Southern Great Plains, Lamont OK, 1 Jan 2019, 1-minute data | ARM Data Center sample file, from the `ARM-DOE/arm-test-data` repository used by ACT's test suite | Unchanged copy. Cite the ARM user facility (U.S. Department of Energy) when reusing. |
| `asos_bwi_iad_dca_2025-08-05_06.parquet` | Airport weather observations at BWI, IAD and DCA | ACT `act.discovery.get_asos_data` (ASOS data served by the Iowa Environmental Mesonet) | 2025-08-05 00:00 to 2025-08-06 23:55 UTC; columns kept: station, time, lon, lat, tmpf, dwpf, relh, spdms, u, v. Optional live fetch in notebook Section 8. |
| `tempo_no2_2026-10-20_midatlantic.parquet` | TEMPO tropospheric NO2 vertical column, one row per pixel (molecules cm-2) | NASA TEMPO Level 2 NO2 through EPA RSIG, using PyRSIG: `RsigApi.to_dataframe('TEMPO2.l2.no2.vertical_column_troposphere')` | bbox (-80, 36, -74, 40.5); 2026-10-20 16:00 to 16:59 UTC (granules starting 16:29 and 16:36); 23,355 pixels; PyRSIG defaults (cloud fraction up to 1.0, quality "normal", solar zenith angle up to 70); coordinates stored as float32. Optional live fetch in notebook Section 8. |
| `tolnet_smol2_hartmiller_20250728_31.parquet` | Ozone mixing ratio (ppbv) from the NASA JPL SMOL-2 lidar at Hart Miller Island, MD (39.24 N, 76.363 W): rows are profile times (UTC), columns are altitude in km above sea level | NASA TOLNet, fetched with `atmoz.lidar.TOLNET().import_data(...)`, HIRES product, centrally processed (GLASS), instrument group 8. DOI 10.5067/Lidar/Ozone/TOLNet/NASA-JPL | 2025-07-28 to 2025-07-31, one file per start date; the per-day tables were joined into one wide table, altitudes saved as text column names (3 decimals), values float32. Optional live fetch in notebook Section 8. |

Format notes: `.nc` and `.cdf` are NetCDF. The repository `.gitignore` ignores `*.nc` in general but makes an exception for this folder, so `geos_cf_midatlantic_aug2025.nc` is tracked.

Known property of the data: on the days shown, the GEOS-CF PM2.5 is roughly two times the monitor values (for 6 Aug 2025 the mean over monitors is 19.0 ug m-3 and the mean of the nearest model cells is 38.3). The notebook shows this on purpose in the Cartopy overlay.
